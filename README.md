# 🏨 Zenvora – Luxury Hotel Booking Platform

Zenvora is a full-stack hotel booking and management web application designed to provide users with a smooth and convenient hotel discovery and booking experience. It also provides an admin interface to manage hotel listings and bookings.

## ✨ Features

### 👤 User Features
- User Registration and Login
- Browse available hotels
- View hotel details and images
- Search and explore hotel listings
- Book hotels
- Manage bookings

### 🔐 Admin Features
- Secure Admin Login
- Admin Dashboard
- Add, Edit and Delete Hotels
- Manage Hotel Listings
- View and Manage Bookings

### 🎨 UI & Design
- Modern luxury-inspired interface
- Responsive website design
- Elegant black and white theme
- Interactive hotel gallery
- User-friendly navigation

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone <your-repository-url>
```

### 2. Navigate to the Project

```bash
cd zenvora-hotel-booking
```

### 3. Install Frontend Dependencies

```bash
cd client
npm install
```

### 4. Install Backend Dependencies

Open another terminal:

```bash
cd server
npm install
```

### 5. Configure Environment Variables

Create a `.env` file inside the server folder and configure the required database and application settings.

### 6. Run the Application

Start the backend and frontend using the development scripts configured in their respective `package.json` files.
